## How to read this

- **Part** is which piece of it, where the file says so on the same line. A blank Part is usually the introduction, a warm-up or a wrap-up; the file and line number say exactly where.

- Lines about "Mission 1" as the place something was made can usually become the step's own name ("in Strengths Mapping") or "earlier".
